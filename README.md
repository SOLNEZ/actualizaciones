# Actualizaciones SOLNEZ

Aquí se publican las versiones vigentes de las apps **SOLNEZ Taller V2** para Android. Las tablets las descargan e instalan solas cuando tienen Wi-Fi.

El catálogo `v2/latest.json` va firmado por SOLNEZ; cada app verifica la firma y la huella de la descarga antes de instalar. Ordenez requiere licencia; Próximo Servicio es gratuito.
